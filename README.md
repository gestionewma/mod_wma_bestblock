# mod_wma_bestblock

Joomla 6 module for configurable bento-style blocks.

Version: `1.0.21`
Release date: `27/08/2026`

## What it does

- Renders multiple sets of blocks.
- Each set includes colors, image fields, text fields, links, and buttons.
- Uses a dedicated backend Information tab with dynamic module version.

Author contact: `wmaextension@gmail.com`

## Notes

- Frontend and backend follow the WMA Joomla 6 standard.
- The Information tab reads module metadata from the installed manifest.
- The `Badge` field is a single-line text field.
